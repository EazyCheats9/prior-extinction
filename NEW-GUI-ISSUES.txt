ISSUE #1 — Auto Cleanliness dead while Legit Farm on (cleanliness stuck) [CONFIRMED LIVE]
------------------------------------------------------------------------
SYMPTOM: "the clean isn't working when legit farm is on." Cleanliness sat frozen
at 75 for a full 30s watch while Legit Farm walked + Force Eat bit (Food swung
640->701, so eating was active). Never rose.

ROOT CAUSE: the game moved the Cleanliness stat. It now lives at:
    CharacterState.Wellbeing.WellbeingReplica.Data.SavableStats.Stats.Cleanliness  (=75 live)
The hub still reads it from the OLD location(s):
  * line ~4200  PX.myCleanliness(): reads PX.getCS().Replica.Data.Cleanliness  -> nil
                (dumped every key of Replica.Data; there is NO Cleanliness field)
  * line ~3347  ReplicaSet listener only catches a TOP-LEVEL "Cleanliness" path
                (path[1]=="Cleanliness", path[2]==nil). The value now updates inside
                the Wellbeing replica (SavableStats.Stats.Cleanliness, different
                replica id), so PX.cleanliness[] never populates.
CONSEQUENCE: PX.myCleanliness() returns nil forever. In the clean loop (~4214-4226)
a nil value skips the re-assert/force branch, so CleanlinessStart is fired exactly
ONCE (dedupe in setCleaning swallows the rest).
  - Farm OFF: the single clean action persists server-side -> cleanliness climbs to
    100 -> looks fine.
  - Farm ON: Force Eat's "Bite" every ~0.8s interrupts the cleaning action
    server-side; with the value read dead, the hub never re-sends CleanlinessStart
    -> stuck.
NOTE: Force Eat deliberately does NOT hold SetAction "Consuming" (see comment
~4062-4069), so this is NOT a Consuming-vs-Cleaning action conflict — it's the
broken value read plus Bite interruptions.
This is a v819 game regression; it also affects plain Auto Cleanliness and AFK-Farm
cleanliness, but Legit Farm makes it obvious.

FIX (later): point PX.myCleanliness() + the ReplicaSet listener at the Wellbeing
replica path/id; likely shorten the CleanlinessStart re-assert interval so it keeps
up with 0.8s bites.
